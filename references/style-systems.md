# Visual Systems & Typography Rules

按需从 `references/catalog.json` 挑选与客户行业气质匹配的方向，或根据企业既有 VI 定制 `4–6` 个命名色值。**禁止在未确认企业调性前直接套用默认配色。**

## 1. 五套行业预设参考方向

1. **高级咨询编辑风 (`consulting-editorial`)**：象牙纸底 + 深松墨绿，适合金融、保险、咨询、政企服务。用粗细规则线、左右不对称分栏和紧凑对比表建立可信度。
2. **温润爱马仕橙品牌风 (`refined-warm-atelier`)**：暖沙白底 + 焦糖橙，适合消费品、品牌机构、制造出海品牌升级。靠大留白和图片比例制造画册呼吸感。
3. **清爽秩序网格风 (`precision-green-grid`)**：微灰绿纸底 + 精密翠绿，适合新能源、医疗健康、SaaS、自动化设备。突出系统架构图与清晰 KPI。
4. **温暖理性技术风 (`rational-warm-ai`)**：暖石纸底 + 赭石点缀，适合 AI、研发型公司、技术咨询。用“结论先行 + 架构图解 + 真实数据”组织内容。
5. **深邃极光工业风 (`obsidian-industrial`)**：深石板底 + 冰蓝点睛，适合硬科技、算力、半导体、高端制造。**极光/氛围光晕仅用于封面、章节沉浸页与结尾，内页保持干净高对比阅读底面。**

## 2. 语义化 Design Tokens 契约

无论 `long-profile` 还是 `deck`，CSS 中必须先定义完整语义变量，内容样式**禁止**直接写死裸十六进制颜色覆盖主题：

```css
:root {
  --paper: #F7F5F0;
  --surface: #FFFFFF;
  --ink: #16202A;
  --muted: #52606D;
  --accent: #1E4D40;
  --accent-soft: #DCE8E4;
  --line: #D8D4CA;
  --font-display: "Noto Sans SC", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
  --font-body: "Noto Sans SC", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
  --font-mono: ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace;
}
```

## 3. 中英文排版与移动可读性规则（融合 `carbonj` + `kubai 007/023`）

- **默认字体与字重层级**：全篇默认 `Noto Sans SC`（思源黑体，附系统本地回退保证完全离线可读）。
  - 封面主标题：`800–900`，紧凑行高 `1.08–1.2`
  - 章节标题：`700–800`，行高 `1.2–1.3`
  - 正文段落：`400–500`，行高 `1.65–1.75`（英文混排较多或衬线体时适当放宽）
  - 指标标签/图注：`500–600`
- **中英文混排细节**：
  - 数字与核心指标统一开启 `font-variant-numeric: tabular-nums`；
  - 中文段落中出现英文短词或专有名词时，合理留白（如借助 `<span lang="en">` 控制字距与字体配对），避免全大写英文标签紧贴长串中文；
  - 可选点缀字体：`Noto Serif SC`（偏人文/咨询标题）、`LXGW WenKai`（温暖引言短句），仅在明确适合品牌气质时引入且必须提供离线回退栈。
- **移动端体验底线**：
  - 正文字号不小于 `15px`（移动视口 `390px` 下禁止出现小于 `12px` 的关键说明文字）；
  - 可点击按钮/导航热区高度不小于 `40px`；
  - 全页在 `1440px / 1024px / 768px / 390px` 均不允许出现横向滚动条。

## 4. 反 AI 模板破绽清单（AI Tells — 自检必过）

生成前与生成后对照以下条目自查，无正当理由不得命中：
1. **SaaS 圆角卡片套盒病**：把公司业务、优势、案例全塞进一模一样圆角 + `rgba(0,0,0,.1)` 灰阴影的格子卡片里。
2. **模板装饰眉标**：每个大标题正上方硬加一行全大写英文小眉标，或滥用 `A · B · C` 中点连接符。
3. **无序硬编号**：不是时间线或先后步骤的内容，却强行加上 `01 / 02 / 03` 编号。
4. **廉价点缀**：标题里故意把一两个词标成强调色/斜体；所有按钮末尾统一加 `→`。
5. **默认渐变**：未得到企业 VI 授权就使用通用蓝紫/荧光绿渐变背景。
