# Inline SVG Charts & In-Place Browser Editing

结合 `carbonj-svg-html` 的核心优势：公司介绍里的关键数据、架构拓扑与发展历程，优先用**独立内联矢量 `<svg>`** 构建，并支持交付后在浏览器里直接改字调色、二次导出。

## 1. 原位编辑属性契约（配合 `assets/editor-runtime.js`）

当用户需要交付可由业务/客户微调的公司介绍 HTML 时（默认在 `long-profile` 和 `deck` 模式下均可开启轻量编辑条），在 HTML 中按以下规则打标：

- **`data-editable-html`**：加在需要支持直接点击改字的标题、副标题、正文段落、指标数字或列表项上。编辑模式下开启 `contenteditable="true"`。
- **`data-editable-text`**：加在原生 `<svg>` 内的 `<text>` 或 `<tspan>` 元素上。点击后在对应屏幕坐标浮现贴合原字号/字重的输入框，实时同步回 `<text>` 节点。
- **`data-editable-shape`**：加在 SVG 中可重新着色的关键图形（如柱状图柱体、流程节点背景、装饰色块 `<rect>`/`<circle>`/`<path>`）上，选中后可通过顶部色盘更改填充色，并支持一键导出该 `<svg>` 图形。

> 编辑栏默认收起为一个低调的角落开关（`编辑内容`），不破坏公司介绍页对外展示时的第一眼品牌质感；打印（`@media print`）与导出 PDF 时自动隐藏工具栏。

## 2. SVG 图表与图形绘制规范

- **保持语义与可导出性**：每个图表用 `<svg viewBox="0 0 W H" role="img" aria-labelledby="...">` 包裹，内部自带 `<title>` 和干净的 `<g>` 分组。
- **常见企业信息图表选型**：
  - **关键指标墙（KPI）**：大号 `tabular-nums` 数字 + 单位 + 对比说明 + 精简趋势迷你折线（Sparkline）。
  - **发展历程（Timeline）**：横向或纵向连线节点，标注年份 + 里程碑事件，保持字数克制。
  - **业务版图 / 技术架构图**：分层矩形/连线箭头，标明角色与流向，节点文字保留充足内边距（padding >= 12px）防贴边裁切。
  - **业务占比 / 增长对比**：内联 SVG 柱状图、环形图或趋势折线图；如果是示范占位数据，**必须在图注或脚注明确标注“演示数据，交付前请替换为实际数据”**。
- **外部图片与版权**：
  - 若嵌入实拍照片，记录来源与授权信息（可在页脚或 `PHOTO-CREDITS.md` 标明 `data-asset-status="licensed"` 或 `"client-owned"`）；
  - 禁止盗用带水印图或无授权链接；无合适实拍图时，优先使用高水准定制 SVG 图形/品牌抽象构图，保证离线打开 100% 完整。
